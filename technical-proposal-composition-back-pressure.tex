\par 背压阀用于在计量泵系统中维持计量泵的背压，
与阻尼器配套可以达到消除系统压力波动、减小计量泵输出流量脉动、使计量泵输出流量更加稳定的目的，
也有防止虹吸的作用。
技术参数：
\begin{itemize}
    \item 数量：3个
    \item 形式：隔膜式
    \item 背压压力可调范围：0$\sim$3bar
    \item 最大耐受压力：10bar
    \item 材质：PVC壳体，PTFE/FKM复合隔膜，接液端为PTFE，背面为FKM
\end{itemize}
