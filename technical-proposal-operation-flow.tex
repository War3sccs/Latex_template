\begin{enumerate}
\item 客户在触摸屏设定制备浓度、制备量、开机液位、停机液位，
  系统将自动根据 储液槽液位 开启、停止。
\item 系统 真空吸料机 可将 高锰酸钾固体 吸至料斗内，
  减轻人工操作工作量。
  料斗带有料斗物位探头，
  料斗料位过低自动停止制备，
  同时发出报警，
  料斗过高时发出报警。
\item 制备时， PLC根据设定参数，自动调节 螺旋进料器 转速，自动控制加粉量。
\item 系统带有进水流量计，
  实时监测进水流量，
  并使用PID算法，
  通过 进水电动阀 自动控制 进水流量。
\item 系统带有压力变送器，
  进水压力过低时报警，
  并自动停止制备过程。
\item 超声波液位计 监测 储液槽液位，
    储液槽液位 低于 开机液位 时 自动开始制备，
    高于 停机液位 时 自动停机。
    同时 有超高液位 和 超低液位 报警，
    超高液位 时报警，
    超低液位 可以投加计量泵联锁，
    报警时 计量泵 自动停泵，
    防止 计量泵 干吸。
\end{enumerate}
