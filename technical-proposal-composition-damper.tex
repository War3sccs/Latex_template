\par 阻尼器用于消除计量泵输出流量中的脉动，减小由此带来的管道系统振动，
增加系统效率和计量泵、管道系统的寿命，使计量泵输出流量更加稳定，确保加药效果。
阻尼器本身带有压力表显示当前充气压力，配备充气阀门。 
技术参数：
\begin{itemize}
    \item 数量：3个
    \item 形式：气囊式
    \item 容积：1.0L
    \item 材质：PVC壳体，FPM隔膜
    \item 最大耐受压力：10bar
    \item 建议充气压力：60\%$\sim$80\%管道系统压力
\end{itemize}
