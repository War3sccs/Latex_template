\par 泄压阀照片参考图\ref{fig:p5-3}。
\par 泄压阀用于在管道系统压力过高时自动泄压，保护计量泵及管道系统。泄压阀设置在计量泵的出口管线上，其出口连接到排液管道。
技术参数：
\begin{itemize}
    \item 数量：3个
    \item 形式：隔膜式
    \item 泄压压力可调范围：0$\sim$6bar
    \item 最大耐受压力：10bar
    \item 材质：PVC壳体，PTFE/FKM复合隔膜，接液端为FKM，背面为PTFE
\end{itemize}
