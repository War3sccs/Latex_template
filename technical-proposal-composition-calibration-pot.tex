\par 标定柱照片参考图\ref{fig:p5-3}。
\par 标定柱的工作原理系根据体积计算法，测定一定时间内计量泵输出液体的容积，对计量泵流量进行标定。
技术参数：
\begin{itemize}
    \item 数量：3个
    \item 容积：1L
    \item 材质：PVC
\end{itemize}


        每台泵配置标定柱，容积1L，PVC材质。通过测定计量泵在一定时间内输出液体的容积，校正计量泵的流量。
