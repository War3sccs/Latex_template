\par 隔膜压力表 照片参考图\ref{fig:p5-2}。
\par 隔膜压力表，内充硅油作传递压力的中间液，适用于测量各种腐蚀性介质管道系统的压力。
技术参数：
\begin{itemize}
    \item 数量：3个
    \item 形式：气囊式
    \item 容积：1.0L
    \item 材质：PVC壳体，FPM隔膜
    \item 最大耐受压力：10bar
    \item 建议充气压力：60\%$\sim$80\%管道系统压力
\end{itemize}
